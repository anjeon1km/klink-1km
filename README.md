# 안키로 · 안전한 1키로 (K-Link 1km)

동대문구를 대상으로 한 **PM(개인형 이동장치)–대중교통 환승취약지역 분석**과 **안전한 마지막 1 km 환승 앱** 프로토타입입니다.
「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」(숲과나눔) 제출용 코드입니다.

- **시민 앱 · 안전한 1km**: 역·정류장에서 목적지까지 남은 1 km를 위험한 길은 빼고 가장 안전한 PM 경로로 안내하고, 환승거점에 제대로 반납하면 환승 할인을 판정합니다. 22시 이후에는 야간 모드로 바뀝니다.
- **정책 대시보드 · K-Link 1km**: 동대문구를 250 m 격자로 나눠 PM–대중교통 환승취약지수(PTVI)와 야간 지수(NIGHT-TVI)를 계산하고, 지역 유형(A~E)별 정책 패키지와 정책 시뮬레이션을 보여 줍니다.

## 바로 실행하기

Node.js 18 이상이 필요합니다 (개발 환경: Node 24).

```bash
npm install
npm run serve
```

브라우저에서 `http://localhost:5173`을 엽니다. 같은 Wi-Fi의 휴대폰에서는 터미널에 표시되는 `http://<PC IP>:5173` 주소로 열 수 있습니다.
`app/index.html`을 파일로 직접 열면 브라우저가 데이터 읽기를 막으므로 꼭 서버로 여세요.

## 정책 기준 (「PM 대중교통 환승제도 편입 정책 개발안」 반영)

- **환승거점**: A 역 환승거점(주차면 30) · B 목적지 거점(대학·병원 입구, 20) · C 보조거점(10) · 야간 안심거점(A·B 중 조명 + CCTV). 시범구간 H1 회기역 1번 출구 · H2 경희대 정문·의료원 · H3 캠퍼스 상부(평화의전당, 오르막 도착 전용) · H4 회기시장 일대(위치 확인 필요).
- **환승구간 등급**: 내리막 5/8%, 오르막 8/15%, 버스·차량 혼용 차도 황색, 비신호 횡단 100 m당 2곳 황색, TAAS 사고다발지점 50 m 적색, 야간 안심구간(조명 + CCTV)이 아니면 야간에 한 단계 상향. C1~C3는 정책안이 고시한 등급(C2 야간 적색, C3 오르막 황색·내리막 적색·야간 전면 적색).
- **안전속도구역**: 녹 20 · 황 15 · 역 출구 100 m 15 · 캠퍼스 10 km/h, 야간 한 단계 낮게.
- **환승 인정**: 태그 전후 30분 · 거점 반납 · 출발 또는 반납이 A·B급 · PM 2 km·20분 이하 · 계정 연동 · 하루 4회. 01~05시는 심야버스 정류장 거점만.
- **할인**: 기본 = 잠금해제료 면제(600원) · 안전 = + 주행요금 마일리지 500M (적색 미통과·속도 준수·정위치 사진) · 야간(22~01시, 야간 안심거점) = + 심야 할증 면제 · 공유 헬멧 인증 + 100M.

  js/ui/citizen|policy/   화면
  data/*.json             파이프라인이 만든 앱 데이터

  01_fetch_osm.js         OpenStreetMap 도로·정류장·행정동 내려받기 (Overpass)
  02_extract_raw.js       원본 공공데이터 → 동대문구 추출본 (data/extract)
  03_build_app_data.js    추출본 → 앱 데이터 (도로 링크, 경사, 횡단, 조명, 거점, 격자 지수)
  fetch_taas.js           (선택) TAAS 사고다발지역 Open API

## 데이터 다시 만들기

```bash
npm run build        # data/extract만으로 앱 데이터 재생성 (원본 파일 불필요)
npm run check        # 등급 분포·시범구간·유형 분포 점검
npm run test         # 시나리오 A·B 경로와 환승 판정 점검
```

원본부터 다시 만들려면 `config/sources.example.json`을 `config/sources.local.json`으로 복사해 경로를 맞춘 뒤 `npm run all`을 실행합니다.
원본: 따릉이 대여소별 OD(2026.9.1–10.2)·대여소 마스터, 버스 노선·정류장별 시간대 승하차(2022.05), 지하철 역별 시간대 승하차, 서울시 가로등, 신호등·횡단보도(2023.05), 수치지도 등고선·표고점(1:5,000), 동대문구 CCTV, 통계청 SGIS 100 m 격자 인구(2024), 도로교통공단 PM 교통사고 합성데이터, TAAS 자전거 사고다발지역(`npm run fetch:taas`). 다운로드 폴더(`~/Downloads`)에 있는 파일도 `config/sources.example.json`의 `anyOf` 후보로 찾습니다.

## 분석 방법 요약

1. **도로 링크**: OSM 도로를 교차점에서 자르고 50 m 이하로 나눔 (22,048개). 등고선·표고점으로 만든 10 m 고도 격자에서 30 m 구간 평균 경사를 방향별로 계산.
2. **구간 등급**: 적색 = 내리막 8% 초과 · 오르막 15% 초과 · 사고다발 50 m · 보도/자동차전용도로. 황색 = 경사 5% 이상 · 100 m당 비신호 횡단 2곳 이상 · 위험 0.5 이상. 야간에는 조명 점수 0.4 미만 구간을 한 단계 올림.
3. **링크 비용**: `Cₑ = Lₑ/vₑ × (1 + w_s·S + w_a·A + w_x·X + w_n·N)`, 적색은 ∞. 다익스트라로 거점→거점 경로 탐색.
4. **격자 지수**: 250 m 격자 중심에서 경사 반영 보행시간(Tobler)으로 역·정류장 도달, PTAL 방식 TAI(주간·22–24시·심야) → A(접근성)·R(위험)·D(서비스 공백)·C(전환 잠재력) 백분위 → `PTVI = 0.30A + 0.30R + 0.20D + 0.20C`.
5. **유형·정책**: 규칙 기반 A~E 유형 + K-means 군집 + TAI×PUI 4유형, 시뮬레이터로 정책 조합 비교.
6. **탄소**: `ΔCO₂ = Σ(대체비중 × 배출계수) − PM 배출계수` (승용차 257.2, 버스 51.0, PM 125.5 g/인·km). 손익분기 승용차 대체율 46.8%.

## 한계와 연동이 필요한 데이터

- **사고 위험(A)**: TAAS는 자전거 사고다발지역만 연동되어 있습니다(다발지점 50 m 적색). '최근 3년 사고 1건 이상 → 황색'은 개별 사고 좌표가 있어야 완전히 적용되며, 그 전까지 교차로·정류장 상충 대리지표를 비용에만 씁니다.
- **야간 조명**: 서울시 가로등은 간선·교량·지하차도 위주이고, 전국보안등표준데이터에는 동대문구 행이 없습니다. 생활도로 조명은 도로 위계로 추정합니다. CCTV는 동대문구 실측(1,367곳)입니다.
- **PM 이용량**: 공유 전동킥보드 OD가 공개되지 않아 따릉이 OD를 대리지표로 씁니다(대여소 마스터로 대여소별 좌표 배정).
- **보호구역**: 어린이·노인 보호구역 내 비신호 횡단(적색) 기준은 보호구역 자료가 있어야 적용됩니다.
- **시범거점 위치**: H2(정문)는 정책안 거리(상부까지 직선 300 m)로, H4(회기시장)는 C1:C2 비율로 추정했습니다. 현장 확인 후 `pipeline/build/hubs.js`에서 고치세요.
- **배차·막차**: 버스 막차는 2022년 5월 시간대별 승차 기록에서 추정하고, 배차 간격은 노선 유형별 가정치입니다.
- **교통약자 경로**: 보도 여부·노면은 OSM 태그(sidewalk, surface, smoothness, wheelchair)와 도로 위계로 추정합니다. 점자블록 위치, 음향신호기, 연석 턱낮춤, 보도 폭, 지하철 엘리베이터 위치 자료가 들어오면 시각장애·휠체어 경로가 정확해집니다. 지금 OSM에서 휠체어 가능으로 표시된 역 출구는 14곳뿐입니다.
- 지수는 동대문구 안 상대 순위입니다.

## GitHub에 올리기 (git이 없을 때)

1. github.com에서 새 저장소를 만듭니다 (예: `klink-1km`).
2. 저장소 화면의 **Add file › Upload files**에 이 폴더의 내용을 끌어다 놓습니다. `node_modules`, `dist` 폴더는 빼세요.
3. 커밋 후 저장소 주소를 분석보고서에 적습니다.
4. (선택) 웹에서 바로 열리는 주소가 필요하면 `app` 폴더를 복사해 `docs`라는 이름으로 함께 올리고, Settings › Pages에서 `main` 브랜치의 `/docs` 폴더를 지정합니다 (GitHub Pages는 `/` 또는 `/docs`만 고를 수 있습니다).
